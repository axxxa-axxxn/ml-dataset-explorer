# ML Dataset Explorer

A beginner-friendly Machine Learning project built using **Scikit-learn** and **Pandas**.

This project explores built-in machine learning datasets and exports them into CSV files for future analysis and model building.

---

## Features

- Load Iris Dataset
- Load Wine Dataset
- Load Breast Cancer Dataset
- Display dataset shape
- Show feature names
- Show target names
- Convert dataset into Pandas DataFrame
- Display first and last rows
- Display dataset information
- Show missing values
- Generate statistical summary
- Show class distribution
- Export datasets to CSV

---

## Technologies

- Python
- Pandas
- Scikit-learn
- NumPy

---

## Built-in Datasets

### Iris Dataset

- 150 samples
- 4 features
- 3 flower classes

### Wine Dataset

- 178 samples
- 13 features
- 3 wine classes

### Breast Cancer Dataset

- 569 samples
- 30 features
- Binary classification
